# Data sources

OutbreakScope never invents data. Every parameter preset below is either **reported** (copied from the cited source), **derived** (computed from sourced numbers; the formula is shown in the app next to the preset), or **assumed** (a hypothetical teaching example with no source, labelled as such). Presets are _illustrative values from the literature_, not predictions about any current outbreak.

Only numbers (facts) are used from these papers; no text, figures or tables are reproduced. Links are opened in the system browser only (https, allowlisted hosts).

Caveats worth knowing:

- Influenza has no sourced incubation period, so its presets use the SIR model.
- Derived infectious periods rest on "serial interval ≈ generation interval" and exponential stage durations; they are rough.
- The Carrat 2008 and Guerra 2017 full texts were not readable here; only the figures stated in their abstracts (as retrieved) were used. The Li 2020 and WHO 2014 numbers were read on their PMC pages. The Biggerstaff numbers were read from the full text.
- Copyright of the papers belongs to their publishers; PMC page notes for Li 2020 and WHO 2014 do not state a Creative Commons licence, which is why no text is copied.

## Sample datasets (Fit mode)

All three are in `datasets/` with a machine-checked manifest (`datasets/manifest.json`); the app shows each one's source, licence, citation, caveats and what was done to the file.

| Dataset                                | What it is                                                                                            | Source and licence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ut-flu-hosp-2024-25.csv` (39 weeks)   | Utah weekly new hospital admissions with confirmed influenza, weeks ending 2024-10-05 to 2025-06-28   | CDC National Healthcare Safety Network, _Weekly Hospital Respiratory Data (HRD) Metrics by Jurisdiction_, data.cdc.gov dataset [ua7e-t2fy](https://data.cdc.gov/d/ua7e-t2fy), retrieved 2026-11-06. Licence field: **Public Domain U.S. Government** ([terms](https://www.usa.gov/government-works)). usa.gov: "Government work is something created by a U.S. government officer or employee as part of their official duties", and "Content on federal websites may include protected intellectual property used with the right holder's permission." The file contains only aggregated weekly counts. |
| `ut-flu-hosp-2022-23.csv` (26 weeks)   | Same series, weeks ending 2022-10-01 to 2023-03-25 (small counts)                                     | Same dataset and licence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `synthetic-seir-weekly.csv` (26 weeks) | Simulated by OutbreakScope (SEIR, R0 2.4, I0 15, rho 0.25, seed 31, Poisson noise); **not real data** | Generated by this app; a unit test regenerates it from the manifest parameters and compares.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

Transformation of the real files: two columns selected for jurisdiction UT and a date window, timestamps shortened to YYYY-MM-DD, counts converted from "388.0" to 388. No value was changed, added or removed. Redistribution verdict: allowed (public domain per the catalogue metadata); keep the attribution.

Population hint: Utah resident population 3,271,616 (2020 Census), [Census Bureau apportionment table E](https://www2.census.gov/programs-surveys/decennial/2020/data/apportionment/apportionment-2020-tableE.pdf). It is not in the dataset and is only offered as a starting value for N.

Not bundled, with reasons:

- 1978 boarding-school influenza: the BMJ item is not open access (Europe PMC lists it as not OA) and the only machine-readable copy found is a re-keyed version in the R `outbreaks` package, which carries a software licence but no data licence.
- Kikwit 1995 Ebola daily series: same situation (Khan et al. 1999, J Infect Dis).
- Project Tycho: licence statements conflict (CCPL / ODbL / "no restrictions"), unresolved.
- CDC NNDSS weekly data (`x9gk-5huc`): no licence field in the catalogue metadata.

You can still import any of these yourself through _File > Open CSV_.
